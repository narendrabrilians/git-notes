# MELIHAT RIWAYAT COMMIT

```bash
git log
```

Menampilkan daftar commit secara lengkap.

## Agar Lebih Sederhana

```bash
git log --oneline
```

Menampilkan commit dalam satu baris per commit.

## Melihat Dalam Bentuk Graph

```bash
git log --oneline --graph
```

Menampilkan commit dalam bentuk grafis cabang (branch).

<br>

# MELIHAT DETAIL COMMIT

## Melihat Commit Terakhir

```bash
git show HEAD
```

Menampilkan detail commit terakhir.

## Melihat Commit Tertentu

```bash
git show hash
```

Menampilkan detail commit berdasarkan hash tertentu.

`Q` atau `q` untuk keluar
