# 🌟 PENGENALAN VERSION CONTROL SYSTEMS

**Version Control System** adalah sistem yang merekam perubahan suatu file atau kumpulan file dari waktu ke waktu, sehingga memungkinkan kita melihat dan mengakses perubahan yang telah disimpan sebelumnya.

Sebagai contoh, jika kita sedang membuat aplikasi dan terjadi perubahan yang tidak diinginkan, Version Control System memungkinkan kita untuk kembali ke versi sebelumnya. Selain itu, jika kita tidak sengaja menghapus kode, kita dapat memulihkannya tanpa harus menulis ulang dari awal.

# 🔍 TIPE VERSION CONTROL

- ## Local Version Control Systems

  **Local Version Control System** adalah sistem version control yang berjalan di komputer lokal kita. Semua perubahan dan versi yang disimpan hanya ada di komputer kita, sehingga kita bisa melacak perubahan kode tanpa perlu terhubung dengan server atau repositori jarak jauh.

- ## Centralized Version Control Systems

  **Centralized Version Control System** adalah sistem version control yang menyimpan seluruh perubahan di server pusat. Jika kita ingin melihat atau mengakses file, kita harus terhubung ke server tersebut.

- ## Distributed Version Control Systems

  **Distributed Version Control System** adalah alternatif dari Centralized Version Control System. Pada sistem ini, setiap client menyalin seluruh repositori, termasuk seluruh histori perubahan, sehingga setiap salinan memiliki riwayat lengkap dari proyek tersebut.

  > ⚡ **Git** adalah salah satu contoh Distributed Version Control System.

# 🚀 PENGENALAN GIT

**Git** adalah **Distributed Version Control System** yang gratis dan open source. Git tersedia untuk berbagai sistem operasi, seperti **Windows, Linux, dan macOS**.

🔗 **Kamu dapat mengunduh Git di [situs resminya](https://git-scm.com/).**
